Adaptive Learning Support - website (one file per page)

HOW TO PUBLISH (Netlify)
1. Log in to Netlify, open your site (or create one) > Deploys > drag this whole folder onto the page.
2. Site configuration > Forms: make sure form detection is on, then redeploy.
3. Forms > Form notifications: add an email notification to info@adaptivelearningsupport.com for each form:
   contact-enquiry, quick-enquiry, aba-enquiry, therapy-enquiry, summer-enquiry, workshop-enquiry, lsa-enquiry, job-application, booking-request
4. Send one test enquiry from each form.

PAGES
index.html (home), services.html, consultations.html, therapy-sessions.html, programmes.html, one page per service,
staff-1/2.html, pricing.html, learn.html + 6 guides, about.html, careers.html, contact.html,
faqs.html, urgent-help.html, book.html, availability.html, 404.html.

NOTES
- Edit text, session lengths and consultant details in site.js (top of the file). Style is in site.css.
- Prices are hidden on the site. The free intro consultation shows as Free.
- Images are in the assets folder.
- CV uploads arrive through Netlify Forms as a download link in the notification email.
- Suggested booking times are placeholders. Speech and occupational therapy have no named therapist yet.
